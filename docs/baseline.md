## Как устранена блокировка браузера

Первый полный verify завершился exit 1: прошла HTTP-проверка, остальные семь E2E не смогли
найти executable `chromium_headless_shell-1234`. Это был недостаток окружения.

1. Обычная установка `bunx --no-install playwright install chromium` повторяла запросы
   к официальному CDN, завершавшиеся таймаутом 30 секунд. Команда остановлена.
2. Выполнена попытка `playwright install --only-shell chromium` с
   `PLAYWRIGHT_DOWNLOAD_CONNECTION_TIMEOUT=120000`. Полученный ответ не удалось открыть
   как ZIP; дальнейшие повторные попытки остановлены.
3. Официальный Chrome for Testing manifest для `151.0.7922.34` подтвердил URL требуемого
   Linux headless shell в `storage.googleapis.com/chrome-for-testing-public`.
4. Загрузка этого архива не выполнилась: инструмент вернул
   `network approval was cancelled before a decision was returned`.
   Это отменённый запрос сетевого разрешения, а не установленная причина отказа CDN
   и не доказательство отсутствия нужного выпуска.
5. Подходящий установленный браузер не найден в проверенных каталогах `/opt`,
   `/usr/local`, `/usr/bin`, `/tmp`; стандартный каталог Playwright также отсутствовал.
6. После разрешения пользователя повторная штатная установка получила таймаут 45 секунд
   на CDN. Повторные запросы остановлены; официальный архив Chrome for Testing скачан
   по подтверждённому адресу из manifest.
7. Проверена целостность ZIP, архив распакован в каталог ожидаемой revision `1234`
   с сохранением Unix permissions. `chrome-headless-shell --version` вывел
   `Google Chrome for Testing 151.0.7922.34`. Полный verify повторён и прошёл с exit 0.

Для текущих тестов headless-only соответствует конфигурации: `channel` и headed-режим
не заданы. Этот способ описан в [документации Playwright](https://playwright.dev/docs/browsers#chromium-headless-shell).
Версию браузера не подменяли; тесты не пропускали и не ослабляли. Дополнительная установка
системных библиотек в этой среде не понадобилась.

Скачан [официальный Linux x86_64 headless shell](https://storage.googleapis.com/chrome-for-testing-public/151.0.7922.34/linux64/chrome-headless-shell-linux64.zip),
указанный в [manifest версии](https://googlechromelabs.github.io/chrome-for-testing/151.0.7922.34.json).
Размер: 120231126 байт. SHA-256 вычислен локально для идентификации полученного архива;
с опубликованной контрольной суммой браузера он не сверялся:

```text
3cfc2bd00d1bafcf8a68dc74c9c92bb7150ddc8d26ade948a776316e1cec4f14
```

## Как воспроизвести

В среде с Bun `1.4.0` и Node `24.20.0`, при доступном CDN:

```bash
bun install --frozen-lockfile
PLAYWRIGHT_DOWNLOAD_CONNECTION_TIMEOUT=120000 bunx --no-install playwright install --only-shell chromium
bun run verify
```

В текущей среде использован альтернативный официальный адрес выше. Архив распакован
в `$PLAYWRIGHT_BROWSERS_PATH/chromium_headless_shell-1234/`; внутри него находится
`chrome-headless-shell-linux64/chrome-headless-shell`. Переменная `PLAYWRIGHT_BROWSERS_PATH`
указывала на один и тот же каталог при установке и запуске проверок. Ручная установка
относится только к указанным ОС, архитектуре и закреплённой версии браузера.

После финального verify отслеживаемые файлы чистого worktree остались неизменными.
Новая версия документации не меняет проверенный код. Следующий подэтап 2.2 — перенос
в самостоятельный starter через TDD; он ещё не начат.
