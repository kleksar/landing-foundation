# Браузерная приёмка — этап 4.2

Дата: 6 сентября 2026 года. Исходная основа: `23c122d`.

**Основной CI прошёл 59 тестов, включая полный Chromium.** Для завершения 4.2
подготовлен отдельный workflow совместимости; успешные 24 E2E ещё не подтверждены.
Ниже сохранена история локальных блокеров и результат первого GitHub Actions run.

## Изменение и границы

Один `playwright.config.ts` содержит четыре проекта с общими восемью E2E:

- `chromium`: полный комплектный браузер, `channel: "chromium"`, modern headless,
  `reducedMotion: "reduce"`. Только он входит в частый `verify` и существующий CI.
- `chrome`: установленный Google Chrome Stable, `channel: "chrome"`.
- `firefox` и `webkit`: соответствующие закреплённые сборки Playwright без Chrome channel.
- Три проекта совместимости используют `reducedMotion: "no-preference"`.

`test:compat` создаёт свежую сборку и запускает эти три проекта. `test:compat:built`
переиспользует готовую сборку. `test:e2e:built` явно выбирает только `chromium`.
Прямой `playwright test` выбирает все четыре проекта. Основной CI устанавливает полный
Chromium с `--no-shell`; совместимость вынесена в отдельный workflow.

Приложение, стили, E2E-сценарии, зависимости, lockfile и навыки не менялись. Новых
библиотек или постоянных настроек обхода ограничений окружения нет. Правила использования
и установки находятся в [стратегии тестирования](../testing.md).

наблюдались два ожидаемых assertion failure на исходной конфигурации, затем 2/2 green.
Ошибка окружения не использовалась как TDD red. Независимая проверка настоящего CLI
`--list` показала ровно 8 тестов `chromium` и 24 теста совместимости.

65 тестов этапа 4.1 относятся к отдельной учебной копии.

## Окружение и блокеры

Ubuntu 24.04.3 LTS x86_64; Bun 1.4.0, Node 24.20.0, Playwright 1.62.1.

| Браузер | Подтверждение версии | Блокер |
| --- | --- | --- |
| Комплектный полный Chrome for Testing 151.0.7922.34, rev 1234 | Бинарник `--version` | `process_singleton_posix.cc`: `socket() Operation not permitted` при launch |
| Google Chrome Stable 152.0.7977.82 | Метаданные официального `.deb` и бинарник `--version` | Системная установка не выполнена: apt не может менять группы/UID; распакованный бинарник также падает на `socket()` |
| Firefox 153.0, rev 1538 | `browser.version()` после launch | Создание страницы завершается timeout; в логе `/proc/self/uid_map: EPERM` и падения дочерних процессов |
| WebKit 26.5, rev 2336 | Закреплённая запись Playwright; runtime-версия не получена | Не хватает OS-библиотек GTK4, GStreamer, Graphene и других; полный список в логе |

Штатный Playwright download Chromium завершился повторными тайм-аутами CDN. Те же
точные архивы получены обычным `curl` по официальным адресам Google / Playwright fallback,
проверены по ZIP CRC и распакованы с Unix permissions в ожидаемые каталоги revision.
SHA-256 рассчитаны для идентификации; с контрольными суммами издателя не сопоставлялись.
Предыдущий headless shell сохранён, но для подмены нового прогона не использовался.

Chrome Stable отсутствовал в системе. После неудачного `playwright install chrome`
официальный `.deb` распакован во временный каталог. Только для диагностики создан отдельный
`playwright.compat.config.mts`, который наследует основную конфигурацию и меняет
`launchOptions.executablePath` проекта `chrome`. Команда:

```bash
bun run test:compat --config /tmp/landing-browser-stage42/playwright.compat.config.mts
```

Это не проверка штатного разрешения `channel: "chrome"`. Постоянного override в основе
нет. Первая временная конфигурация `.ts` не загрузилась как ESM; после исправления на
`.mts` матрица запустилась и зафиксировала перечисленные ошибки среды. Проверки страницы
не ослаблялись; ограничения ОС не изменялись.

## Ревью, доказательства и следующий шаг

Независимый read-only критик проверил diff и наблюдаемые red/green/CLI-результаты.
Технических замечаний к конфигурации не выявлено. Его требования явно различать запуск
бинарника, успешную проверку страницы и временный Chrome override включены в этот отчёт.

Архив контрольной точки содержит исходники отдельно от `evidence/browsers/`:
`red.log`, `green.log`, `list-main.log`, `list-compat.log`, `verify.log`, `compat.log`,
ошибку первой временной конфигурации, её исправленный вариант, отчёты установки/версий,
логи launch и неудачной системной установки Chrome. Абсолютные временные пути в логах
описывают эту сессию; это не пути установки будущего проекта. Бинарники в архив не входят.

## GitHub: основной CI подтверждён, совместимость подготовлена

Пользователь применил перенос проекта в корень и отправил его по SSH. Коммит `c9f417c`,
[run 34063589819](https://github.com/kleksar/landing-foundation/actions/runs/34063589819),
6 сентября 2026: **success**, 59 тестов (34 unit + 10 repository + 7 build contracts +
8 Chromium E2E), без повторных попыток. Lint, typecheck, production build и audit прошли;
audit не нашёл уязвимостей на момент запуска. Ubuntu 24.04 runner установил полный
Chrome for Testing 151.0.7922.34, rev 1234. Локальные блокеры выше не относятся к этому runner.

Следующее изменение добавляет `.github/workflows/compatibility.yml`. Один job устанавливает
Firefox/WebKit вместе с OS-зависимостями и обновляет предустановленный Chrome до Stable
штатным `playwright install chrome --force`. Переустановка касается только одноразового
runner. `browser.version()` фиксирует фактические версии; затем существующий `test:compat`
собирает сайт и выполняет 24 E2E одним worker. Новых зависимостей и изменений E2E нет.

Новый repository-контракт сначала упал на отсутствии workflow в корне, затем прошёл.
Он разбирает настоящий YAML встроенным Bun parser и защищает запуск, подготовку браузеров
перед E2E и отсутствие маскировки ошибок. Основной CI и настройки браузеров не изменены.

Текущий локальный `bun run verify` после изменения: lint, typecheck, production build и
52 теста нижних слоёв (34 unit + 11 repository + 7 build contracts) прошли; общий exit 1.
В E2E повторился прежний запрет `socket()` — 7 ошибок запуска Chromium и 1 успешный HTTP 404.
Это не новый полный зелёный verify. `bun run test:compat --workers=1 --list` создал сборку
и выбрал ровно 24 E2E, но не исполнял браузерные сценарии. YAML, shell и встроенный JavaScript
проверены на синтаксис, локальные Markdown-ссылки разрешаются. Независимое read-only ревью
не выявило замечаний; единственное непроверенное условие приёмки — реальный новый CI.

Для закрытия 4.2 применить новый патч и отправить его по SSH: изменение workflow само
запустит совместимость. Проверить оба workflow на новом коммите; записать URL, SHA,
фактические версии, количество тестов и повторы; исправить выявленные проблемы.
**Удалённый запуск этого нового workflow пока не выполнен; совместимость не принята.**
Ручной повтор перед выпуском описан в [testing](../testing.md). Повторять установки
в неизменном локальном окружении не нужно.

Прохождение будущей матрицы не будет доказательством визуального качества, полной
доступности или Safari/iOS-совместимости. WebKit Linux не равен Safari на реальном устройстве;
обычный motion-режим не заменяет осмотр анимации конкретного сайта.
