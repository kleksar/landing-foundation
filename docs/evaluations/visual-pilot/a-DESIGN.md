# МЕРА — выбранная визуальная композиция

## Основание и статус

Направление выбрано по делегированию из [BRIEF.md](BRIEF.md). Это выполненная локальная
визуальная проба, а не отдельно утверждённый пользователем фирменный стиль.
Просмотрен только поставленный `reference.png`: полезны крупный заголовок, свободное поле,
тонкие направляющие, линейная геометрия и один сигнальный цвет. Английские подписи не перенесены.
Внешние каталоги, upstream-сайты и референсы не просматривались.

## Композиция

Первое внимание получает задача «Контроль геометрии прямо на линии». Ниже инженер читает
назначение системы и видит «Посмотреть параметры». Схема справа поддерживает тему измерения;
она явно подписана как условная и не обещает точность реального оборудования. Три параметра
отделены горизонтальной линией; контакт завершает компактный блок.

| Область | Правило |
| --- | --- |
| Контейнер | Максимум 1600 px; поля `clamp(22px, 4.45vw, 72px)` |
| Шапка | МЕРА слева, демо-описание справа, нижняя линия; без меню |
| Заголовок | Во всю ширину; на широком экране две смысловые строки |
| Основная часть | Две колонки 0.9fr / 1.1fr, интервал 30–80 px; описание слева, схема справа |
| Параметры | Три столбца 1fr / 1.4fr / 1fr, интервал 40 px; интерфейсам дано больше места |
| Узкий экран | При ширине до 760 px один столбец: заголовок, описание, действие, схема, параметры, контакт |
| Строки параметров | На узком экране название над значением; строки разделены тонкими линиями |

Breakpoint 760 px выбран для места, необходимого русскому описанию и схеме рядом. Фиксированных
высот секций нет. Длинный заголовок на узком экране переносится естественно: широкие принудительные
строки отключаются. Значения параметров допускают перенос, в том числе перед дискретным I/O.

## Типографика

Системный стек `Arial, Helvetica, sans-serif`; файлы шрифтов отсутствуют и не загружаются.
Кириллическое начертание зависит от доступного системного шрифта; идентичность между ОС не обещана.
Заголовок: 48–108 px, вес 700, интерлиньяж 0.99, трекинг −0.052em; на узком экране 43–67 px,
интерлиньяж 1.04 и трекинг −0.045em. Описание: 19–25 px / 1.45, мера до 470 px на широком экране.
Основное действие: 16 px / 1.35. Значения параметров: 23–33 px / 1.2, на узком экране 26 px.
Второстепенные подписи: 11–15 px; они не несут единственного экземпляра основного действия или параметров.

## Цвет и геометрия

| CSS-роль | Значение | Применение |
| --- | --- | --- |
| `--paper` | `#eeece4` | Фон и светлый текст действия |
| `--ink` | `#202923` | Основной текст, схема, фон действия |
| `--muted` | `#535e55` | Второстепенные подписи |
| `--line` | `#bac0b5` | Декоративные разделители и направляющие |
| `--signal` | `#bc3d21` | Метка логотипа, линия в схеме, стрелка контакта, hover контакта |
| `--focus` | `#1b4f68` | Клавиатурный outline |

Прямые углы, без теней и объёмных карточек. Базовые интервалы опираются на 8 px с оптическими
поправками. Разделители декоративные; их контраст не используется для передачи обязательного
содержания. Локально рассчитаны пары цветов: основной текст / фон 12.66:1; второстепенный
текст / фон 5.73:1; оранжевый / фон 4.64:1; focus / фон 7.51:1; светлый текст / hover
действия 8.91:1; светлый текст / active 15.06:1. Это расчёт непрозрачных цветов, не полный аудит.

## Действия и состояния

Главное действие — семантическая ссылка на `#parameters`, высотой минимум 54 px, с направленной
вниз SVG-стрелкой. Hover меняет графитовый фон на `#364238`, active на `#101a13`; текст светлый.
Контакт — подчёркнутая ссылка `mailto:demo@example.com`, высотой минимум 44 px; hover оранжевый,
active графитовый. При `:focus-visible` обе ссылки получают outline 3 px с отступом 6 px.
Ссылка пропуска появляется при фокусе. Нет sticky-элементов, способных закрыть фокус или якорь.
Форм, отправки, загрузочных, недоступных и успешных состояний в пробе нет.

## Графика и движение

Встроенная SVG-схема построена для этой пробы, не является изображением клиентского оборудования.
Она декоративная (`aria-hidden`), масштабируется по ширине без внешних ресурсов; подпись сообщает
её условный характер. `reference.png` использован только при выборе направления, не загружается страницей.
Анимации и плавной прокрутки нет. Всё содержание и обе ссылки доступны в исходном HTML без JavaScript;
для reduced motion отдельная ветка не нужна, поскольку движение отсутствует.

## Проверка

Просмотрены фактические первые viewport, полные страницы и состояния клавиатурного фокуса
при 1440 × 900 и 390 × 900 — шесть снимков из `evidence/`. На широком экране заголовок занимает
две строки, графика и описание сохраняют иерархию; на узком заголовок переносится в четыре строки,
описание и CTA предшествуют схеме. Три параметра и контакт читаются целиком на полном снимке.
Обрезки, перекрытий или пропавших ресурсов не наблюдается; focus-outline виден полностью.

JSON-протоколы координатора в `evidence/a-1440.json` и `evidence/a-390.json` подтверждают отсутствие
горизонтального переполнения, фокус CTA, переход клавишей Enter к видимому `#parameters`, пустые
списки axe-нарушений и браузерных ошибок. Отдельный тест без JavaScript и точность строк h1/CTA
подтверждены координатором. После этих снимков HTML не изменялся.

Это проверка локального фрагмента в portable Chromium 153.0.8010.0, без React-сборки и штатного CI.
Firefox, WebKit, 200% zoom, 320 px и screen reader отдельно не проверены. Отсутствие axe-нарушений
и расчёт цветов не являются полным подтверждением WCAG. Конкретных неустранённых дефектов
в проверенных состояниях нет.
