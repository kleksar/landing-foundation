# МЕРА — локальная визуальная проба

Выбор выполнен агентом по делегированному оформлению из `BRIEF.md`. Это одна композиция
для синтетического продукта, не принятый клиентом бренд и не изменение оформления starter.
Реализация ограничена `preview.html`; обязательный текст и действия заданы в `BRIEF.md`.

## Композиция и референс

Осмотрен `reference.png`: крупный заголовок, широкие свободные поля, тонкие горизонтальные
границы и объёмная линейная схема с одним оранжевым сигналом. В пробе эти качества дают
порядок внимания: задача контроля → объяснение и переход → условная схема → параметры.
Английский текст, вымышленные номера образца и материал из референса не перенесены.

- На 1440 px внешние поля 64 px, ширина содержимого 1312 px. Шапка на одной строке;
  заголовок разделён на две смысловые строки. Ниже — описание/действие слева и схема справа,
  две равные колонки с промежутком 64 px. Высота определяется содержимым.
- Параметры объединены в линейный блок с тремя колонками 1 / 1.3 / .8; контакт вынесен
  на завершающую строку. Линии помогают сравнить характеристики без отдельных карточек.
- До 1000 px поля уменьшаются до 32 px. До 700 px — 24 px и одна колонка:
  заголовок, описание, действие, схема, параметры, контакт. Заголовок допускает переносы
  внутри смысловых строк. Интерфейсы не усечены; значения параметров могут переноситься.
- До 350 px поля 18 px и заголовок 35 px. Фиксированных высот текстовых блоков нет.

## Типографика и цвет

Системный стек Arial / Helvetica / sans-serif; отдельные шрифтовые файлы не добавлены.
Фактический шрифт зависит от системы; точное межплатформенное совпадение не заявлено.
Заголовок: вес 600, 6.8vw в диапазоне 54–108 px, интерлиньяж 1.01, трекинг −.055em.
На узком экране: 10.8vw в диапазоне 39–69 px, интерлиньяж 1.04.
Описание: 18–23 px / 1.45, до 525 px. Основная ссылка: 16–17 px; значения: 22–31 px,
на мобильном 25 px. Служебные подписи 12–14 px; подпись схемы 11–12 px, Courier New.

| Роль | Значение |
| --- | --- |
| Бумажный фон | `#eeece5` |
| Основной текст и кнопочная ссылка | `#202823` |
| Вторичный текст | `#5e665f` |

Основная ссылка — прямоугольник без радиуса высотой от 58 px (56 px на узком экране).
Светлый текст на тёмной поверхности; hover `#39463b`, active `#0d140f`.
Фокус: контур 3 px с отступом 6 px. Контакт подчёркнут постоянно, при hover меняет цвет.
Оранжевый цвет не служит единственным обозначением действия: ссылки имеют текст и стрелку.
Цели по доступности — видимый фокус, читаемый контраст и отсутствие переполнения;
это не заявление о полной проверке WCAG.
Рассчитанные пары с фоном: основной текст 12.79:1, вторичный 5.02:1, акцент 5.12:1,
контур фокуса 6.94:1. Светлый текст на hover главной ссылки — 8.41:1.
Акцент был затемнён после расчёта прежнего hover контакта 4.31:1.

## Графика и движение

Собственная векторная схема в inline SVG: условная геометрическая деталь с проёмом,
координатное поле и линия через контрольные точки. Не фотография и не технический чертёж
реального изделия; видимая подпись прямо называет её условной схемой.
Графика масштабируется по ширине, без обрезки, с title/desc. Стрелки ссылок декоративные.
Внешних изображений, шрифтов, зависимостей и JavaScript нет. Анимации и плавный скролл
не применены; содержание сразу доступно при выключенном JavaScript и reduced motion.

## Проверка

Сначала подготовлен этот характерный фрагмент. Осмотрены первые экраны, полные страницы и
состояния фокуса при viewport 1440×900 и 390×900. На широком экране заголовок занимает две
строки, на узком — четыре; порядок чтения и длинные значения сохранены. Контуры фокуса
не обрезаны. Наблюдаемых дефектов композиции и переноса текста не найдено.
Фактические пути, метрики Chromium 153 portable и ограничения проверок — в `PROJECT.md`.
