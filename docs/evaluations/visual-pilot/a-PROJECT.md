# МЕРА — локальная визуальная проба

## Текущая задача

- Режим: синтетическая визуальная проба в изолированной копии существующего проекта.
- Основание: [BRIEF.md](BRIEF.md); исходный материал: [reference.png](reference.png).
- Аудитория: инженеры производства, оценивающие оптический контроль деталей.
- Результат: [preview.html](a.html), первый экран и компактный блок параметров с контактом.
- Это не реальная компания и не продолжение разработки foundation. Исторический
  [SITE_SPEC.md](../../../SITE_SPEC.md) описывает starter; содержание этой пробы задаёт BRIEF.md.

## Подтверждено заданием

- Одна композиция, выбор оформления делегирован; дополнительных согласований не требуется.
- Только локальный HTML/CSS, без React-сборки, публикации и новых зависимостей.
- Сохранены заданные русские тексты, параметры и адрес `mailto:demo@example.com`.
- Основное действие — обычная ссылка `#parameters`. Письма не отправляются.
- Никаких клиентов, сертификатов, точности, сроков, цены и отзывов не добавлено.

## Выполнено

- Написан самодостаточный `preview.html`: HTML, встроенные CSS и декоративная SVG-схема.
- Выбрана типографическая композиция с тёплым фоном, тонкими линиями, графитовым текстом
  и дозированным оранжевым акцентом. Конкретные правила записаны в [DESIGN.md](a-DESIGN.md).
- На широкой компоновке описание и действие соседствуют со схемой; ниже идут три параметра
  в строку. На узкой — один столбец, сначала весь смысл и действие, затем схема и параметры.
- Предусмотрены видимый фокус ссылок, ссылка пропуска к содержанию, нативный якорный переход.
  JavaScript, загрузки шрифтов, внешние изображения и анимация отсутствуют.

## Проверка и следующий шаг

- Независимое read-only ревью `AGENTS.md`, `BRIEF.md` и исходника `preview.html` завершено:
  конкретных статических дефектов не найдено. Это отдельно от браузерной проверки.
- Проверены пробелы в конце строк трёх изменённых файлов: не найдены. Рассчитаны используемые
  пары цветов; значения записаны в DESIGN.md.
- Координатор выполнил локальные тесты в portable Chromium 153.0.8010.0 при 1440 × 900
  и 390 × 900. Прочитаны фактические [широкий](evidence/a-1440.json) и
  [узкий](evidence/a-390.json) JSON-результаты: ширина документа равна viewport, основной CTA
  получает клавиатурный фокус с outline 3 px, Enter приводит к видимому `#parameters`,
  axe не выявил нарушений, массив ошибок пуст.
- Лично просмотрены все шесть переданных снимков: первый viewport, полная страница и фокус CTA
  при обеих ширинах. Заголовок, описание, параметры и контакт читаются без обрезки и перекрытий;
  на 390 px длинные русские строки размещаются в одной колонке. Главное действие присутствует
  в первом viewport; outline полностью виден. Конкретных визуальных дефектов не обнаружено.
- Координатор также сообщил успешную отдельную проверку без JavaScript и соответствие h1/CTA
  заданным строкам. В HTML отсутствуют скрипты; самостоятельный второй браузерный запуск не делался.
- Разметка после получения снимков не менялась: оснований для исправления наблюдаемых дефектов нет.
- React-сборка и `bun run verify` не запускались: BRIEF ограничивает задачу HTML/CSS-фрагментом
  без React-сборки. Portable Chromium 153 не подменяет штатный CI на Chrome 151. Firefox, WebKit,
  200% zoom, 320 px и screen reader отдельно не проверялись; это не полный аудит WCAG.
- Локальная проба завершена в запрошенном объёме. Следующий шаг — оценка выбранной композиции
  координатором; развёртывание и перенос в приложение не входят в текущую задачу.
