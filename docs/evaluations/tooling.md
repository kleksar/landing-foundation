# Проверка выбора библиотек и ресурсов

Дата: 6 сентября 2026 года. База основы: `c9d6988`, этап 3.4.
Проверяем новый `landing-tooling` и маршрут из `AGENTS.md`. Пакеты-кандидаты не устанавливаем:
это проверка решения перед реализацией, а не готовых интеграций.

## Условия и критерии

Независимый критик прочитал ограничения основы и до испытаний предложил два разных брифа
и критерии. Для каждого брифа подготовлена отдельная копия исходников с клиентскими
`PROJECT.md`, `SITE_SPEC.md` и `DESIGN.md`, без истории чата, зависимостей и старых загрузок.
Запрос передан новому агенту вместе с путём checkout и указанием прочитать `AGENTS.md`;
ожидаемые ответы, критерии и результаты других агентов ему не передавались.

Критерии смысловой оценки:

1. Выбор следует согласованным требованиям, оформлению и существующему статическому стеку.
2. Новая зависимость либо не нужна, либо имеет конкретную причину; сложное взаимодействие
   не предписано писать вручную только ради минимального числа пакетов.
3. Релиз, стабильность, совместимость и условия использования опираются на первичные
   источники с датой; новизна не заменяет пригодность.
4. План учитывает prerender, hydration, доступный без JS контент, клавиатуру, фокус и motion.
5. Заявления автора о размере отделены от фактических измерений; выдуманных результатов нет.
6. Доступность материалов и разрешение на них не додумываются; отсутствующие файлы
   не блокируют независимую часть следующего шага.
7. Решение пригодно следующей сессии; в задаче только на выбор нет установки, кода,
   подключения сервиса или лишнего согласования.

Это сценарии, созданные для проверки. Данные прежних клиентов не использованы. Реальных фото,
скриншотов и шрифтов нет: брифы явно говорят, что файлы ещё не переданы в checkout.

## Запросы

**Мастерская «Тетрадь».** Согласованы вступление, три вида работ, передача книги и контакт
по телефону. Бумажный фон, крупная типографика, тонкие линии; возле вида работ один снимок.
Клиент сообщает о шести своих фотографиях с разрешением для сайта, но файлы ещё не передал.
Нет увеличения, слайдера, видео или формы. Требуется только выбрать средства и сохранить
решения для реализации, без установки и кода; не задавать вопросов, если выбор уже возможен.

**Портфолио «Ракурс».** Три серии по 12 снимков, минималистичное оформление согласовано.
Нужны крупный просмотр, свайп, клавиатура, увеличение деталей и возврат к исходному снимку;
сами серии и подписи доступны без JS. Клиент сообщил о 12 превью 1200px с водяными знаками
и разрешением для этого сайта; остальные снимки и оригиналы ожидаются. Файлов в checkout
нет. Два Pinterest-скриншота — референсы, платный Suisse Intl назван без файла и лицензии;
в DESIGN уже предусмотрен временный системный шрифт. Требуется обоснованный выбор стабильной
библиотеки и работа с ограничениями материалов, без кода, установки и внешних подключений.

## Источники справки

Исследователь проверил официальные документации и опубликованные npm metadata: даты релизов,
каналы, лицензии и peer dependencies. Небольшая справка навыка содержит четыре условных
кандидата и исходные ссылки. Состояние на 3 сентября отделено от проверки 6 сентября:
обновления Base UI и Lucide от 4 сентября не выданы за доступные на исходную дату.

Справка не доказывает совместимость в сборке, размер или отсутствие уязвимостей всех кандидатов.
Версии выбранной библиотеки и нужного API перепроверяются перед внедрением; весь каталог
не пересматривается при каждой правке сайта.

## Фактические результаты

| Сценарий | Решение | Материалы и ограничения |
| --- | --- | --- |
| «Тетрадь» | Существующий стек, семантический HTML, CSS, `tel` и адаптивные локальные изображения; новых зависимостей нет | Ни одного фото не объявлено полученным; запланированы три снимка после осмотра, системные шрифты, подготовка размеров и проверка бюджета |
| «Ракурс» | Выбран `photoswipe@5.4.4` без React-обёртки; статические серии и ссылки дополняются просмотром после hydration | Отделены 12 заявленных превью от 36 запланированных снимков; водяные знаки сохраняются, Pinterest не используется как источник чужих работ, платный шрифт ожидает файлов и условий использования |

Оба агента сохранили исходные `SITE_SPEC.md` побайтово. Изменены только `PROJECT.md` и
`DESIGN.md`; новых файлов в копиях нет. Код, конфигурации и lockfile сохранены. Дополнительных
уточняющих вопросов и действий во внешних аккаунтах не было. В обоих испытаниях прочитана
одна и та же версия навыка.

Для портфолио агент проверил stable-флаги релиза, npm metadata и конкретные API PhotoSwipe;
GitHub Advisory API для указанного npm-релиза вернул пустой список. Результат одного
источника явно не назван гарантией отсутствия уязвимостей или аудитом интеграции. В handoff
есть границы серий, жизненный цикл, клавиатура/фокус, подписи, no-JS и fallback при ошибке,
reduced motion и будущие проверки фактической стоимости. Некоторые меры, например
клавиатурное перемещение увеличенного снимка, обозначены как будущая локальная доработка,
а не готовая возможность библиотеки. Возможность качественного увеличения ограничена
реально полученными исходниками; макет не выдан за готовые 36 работ.

## Независимое ревью

Критик проверил инструкции, источники и оба результата; существенных замечаний нет.
Включено одно уточнение после испытаний: запрет подменять получение разрешённых исходников
удалением водяного знака не превращается в запрет любой будущей разрешённой работы с
собственными материалами. Для двух текущих брифов решения не меняются. Повторная проба
для этой редакционной конкретизации не проводилась; итоговая формулировка отдельно
проверена критиком. Остальной текст навыка совпадает с испытанной версией.

навыков, установка внешних плагинов и GitHub-коннектор не испытывались.
