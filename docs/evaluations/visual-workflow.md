## Изменение процесса

- `AGENTS.md` явно связывает все шесть локальных навыков; `CLAUDE.md` импортирует общий вход.
- Новый сайт, включая реализацию готового `DESIGN.md`, использует `landing-design` и первую
  визуальную приёмку `visual-qa` с rendered-review адаптером.
- Просмотренный референс связывается с конкретным решением. При новом направлении сначала
  проверяется характерный HTML/CSS-фрагмент на широком и узком экране, затем расширяется страница.
  Это внутренняя рабочая проверка, не дополнительное согласование с пользователем.
- В `PROJECT.md` сохраняются прочитанные инструкции, применённые решения, действительно
  просмотренные изображения и результаты проверок. Reviewer открывает изображения, а не
  принимает их наличие или зелёные технические тесты за доказательство качества.
- video-shotcraft доступен как условный источник приёмов и способа визуальной работы;
  его код, медиа, Remotion и workbench не установлены в приложение.

## Проверки инструкций

Контракты проверяют наличие шести навыков и маршрутов, импорт общего входа, обе связи с UX/UI
адаптером, локальные Markdown-ссылки и heading anchors. Fixtures намеренно содержат отсутствующий
файл и неверные якоря. Это защита целостности, не тест мышления или автозагрузки модели.

- Изолированный baseline с новыми тестами: 2 ожидаемых падения — неполные маршруты `AGENTS.md`
  и отсутствующий `CLAUDE.md`. Рабочие файлы для red не подменялись.
- Исправленная версия: `bun run test:repo` — 18/18; lint и typecheck проходят.
- `quick_validate.py`: `landing-design`, `visual-qa`, `landing-tooling` валидны.
- `bun run audit`: уязвимостей не найдено, проверено 192 пакета.
- В локальном `bun run verify` прошли 34 unit, 18 repository, 7 build contracts, production build
  с prerender и HTTP-тест 404. 7 browser-тестов не стартовали: штатный Chromium отсутствовал,
  его загрузка с CDN завершалась таймаутом. Этот запуск **не является успешным verify**.

### Реальные тесты и исправления

Тестовый runner [pilot.spec.ts](visual-pilot/pilot.spec.ts) обслуживает статические HTML по HTTP,
снимает 1440 × 900 и 390 × 900, проверяет текст и ссылки, отсутствие горизонтального overflow,
переход клавишами Tab/Enter, axe и отдельный контекст без JavaScript. Письма не отправлялись.
Снимки сохраняются до проверок содержимого, чтобы видеть и ошибочный результат.

Локальные снимки получены portable Chromium 153.0.8010.0 из `@sparticuz/chromium@153.0.0` в отдельном
тестовом окружении. Пакет не добавлялся в зависимости приложения. Это другой браузер, чем
закреплённый штатный Chrome for Testing 151; снимки не выдаются за результат основного CI.

| Проверка | A | B после исправления |
| --- | --- | --- |
| 1440 px: текст, overflow, focus, основной переход, axe | Пройдено | Пройдено |
| 390 px: те же проверки | Пройдено | Пройдено |
| Основной переход без JavaScript | Пройдено | Пройдено |

Первый прогон B остановился на точном тексте h1: две span-части были склеены без пробела и
добавлена точка. Агент восстановил заданный текст, сохранив композицию. Отдельный статический
расчёт агента выявил недостаточный контраст hover-контакта; он затемнил акцент. После этих правок
три B-проверки пройдены повторно. Начальная ошибка не скрыта за итоговым зелёным результатом.

### Повторить

Из корня установленного проекта, с Python 3 и штатным браузером Playwright:

```bash
bunx --no-install playwright test --config docs/evaluations/visual-pilot/playwright.config.ts
```

Для явно выбранного локального test-browser конфигурация принимает `PILOT_CHROMIUM_PATH`.
Фактическая версия записывается в JSON; подмена результата штатного `verify` не допускается.
Повторы пишут в `test-results/visual-pilot/evidence/`. Сохранённые здесь изображения и JSON
не перезаписываются: новая контрольная точка переносится из test-results отдельным изменением
только после просмотра снимков и обновления выводов о браузере и результатах.
Эта отдельная проба не включена в обычный CI и не делает её оформление общим стилем starter.

## Что осталось непроверенным

В среде этой сессии нет jcode, Claude Code или Codex CLI. Настоящая автозагрузка в рабочем клиенте
пользователя не проверена. [Workflow](../workflow.md#доступ-в-новой-сессии) описывает вход и способ
проверки `/context` для Claude Code; для форка jcode нужен его фактический trace. Текстовый журнал
агента и repository tests не заменяют эту проверку.

Один бриф и одна пара запусков не показывают общего преимущества по красоте, времени или
стоимости. Сохраняем конкретный результат и наблюдаемые дефекты, не объявляем статистическую
победу обновлённого навыка. Совместимость трёх браузеров (этап 4.2) и выпуск template остаются
в своих границах.
