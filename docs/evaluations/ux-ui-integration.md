# Проверка адаптации UX/UI-навыков

Дата: 12 сентября 2026. База проекта: `f333f7f12a8bcbf04bd48a8e4a976048aa006418`,
сверена с GitHub `main`. Upstream: `plugin87/ux-ui-agent-skills`, `2.5.1`,
commit `2ffb677aa02b225c8a3da1b7f31d9ebb7c38f1dd`.

## Объём

Существующие `landing-design` и `visual-qa` направляют к одной
[локальной адаптации](../../.agents/skills/landing-design/references/ux-ui-agent-skills.md)
при существенном планировании или ревью. Там сохранены закреплённые первичные источники,
условия обновления и отличия от upstream. Для обычной локальной правки новый обзор не нужен.

Пакет, CLI, сторонние SKILL.md, библиотека брендов, DTCG-токены, настройки Claude/MCP,
зависимости и upstream-gates не устанавливались. MIT указан в upstream README/package.json;
отдельного LICENSE/NOTICE в просмотренном дереве нет. Исходные файлы не копировались;
эта проверка не предоставляет прав на чужие изображения, логотипы и шрифты.

Причины выборочного подхода: жёсткие вкусовые запреты и второй процесс спецификации
конфликтуют с независимыми дизайнами основы. Проверенный `taste_audit.mjs` рассчитан на
`file://`, содержит эвристические критерии и допускает exit 0 при отсутствии Playwright
без `DS_REQUIRE_BROWSER=1`. Его результат не равен проверке нашего served production build.
Это статический разбор исходника, не runtime-испытание upstream.

ZIP содержит незакоммиченные правки `PROJECT.md`, `README.md`, `docs/roadmap.md` и отдельные
исследовательские файлы. Они не потеряны и не включены в этот PR: изменения сделаны в чистой
копии отслеживаемого коммита. Архив не переписывался.
