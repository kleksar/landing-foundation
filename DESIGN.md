# Starter visual contract

The starter demonstrates replaceable structure, not a shared brand.

- Direction: editorial utility with high-contrast typography and one orange signal color.
- Layout: a single-column hero followed by a two-column contract summary on wide screens.
- Minimum body text: 16px; controls remain usable at 200% zoom.
- Motion: CSS only, short interaction feedback, and full `prefers-reduced-motion` support.
- Assets: no remote fonts, external images, or nondeterministic content.
- A new landing must replace these tokens and composition according to its own `DESIGN.md`.
